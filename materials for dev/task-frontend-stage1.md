# Задание — Этап 1: Доработка фронтенда «Космическая Станция Максима»

## Контекст

Уже сверстаны следующие экраны (не трогать, только использовать как визуальный эталон стиля):

| URL | Описание |
|-----|----------|
| `/` | Главная — станция в норме (синяя тема) |
| `/warning` | Станция на грани (жёлтая тема) |
| `/danger` | Станция в опасности (оранжевая тема) |
| `/critical` | Аварийное состояние (красная тема) |
| `/drum` | Барабан наград (золотая тема) |
| `/drum2` | Барабан последствий (красная тема) |
| `/log` | Журнал событий |
| `/admin` | Вход в центр управления (PIN-экран) |
| `/admin/event` | Записать событие |

Все новые экраны и доработки должны строго соответствовать существующей дизайн-системе: тёмный космический фон, шрифты, цвета, карточки, анимации — всё как в уже готовых экранах.

## Задача 1 — Доработать `/log`

**Что нужно добавить:**

Вверху экрана, над лентой событий, добавить две вкладки-переключателя:

- `📋 СОБЫТИЯ` — текущий вид журнала (без изменений)
- `🎁 НАГРАДЫ И ПОСЛЕДСТВИЯ` — второй таб, пустой список с тем же стилем карточек (данные подключим позже на бэкенде)

Активный таб подсвечен (cyan border снизу), неактивный — приглушён.

**Поведение при авторизованном родителе:**
Если в `localStorage` есть `role` (papa / mama / babushka), на каждой карточке события справа появляется иконка 🗑️ (серая, при hover — красная). При нажатии — модальное окно подтверждения:

```
─────────────────────────────
  Удалить событие?
  Это действие нельзя отменить.

  [ОТМЕНА]    [УДАЛИТЬ]
─────────────────────────────
```

Нажатие «УДАЛИТЬ» → карточка исчезает с анимацией (fade + slide up). Реальное удаление из БД — позже на бэкенде, сейчас только визуал.

## Задача 3 — Создать `/admin/chests`

Новый экран. Стиль — точная копия `/admin/event` (та же шапка, те же блоки-секции с нумерацией 01/02/03/04, та же кнопка внизу).

**Шапка:**
`← (назад на /admin/event) | ПАПА / ДОСТУП | →(выход)`
Иконки 🎁 нет (мы уже здесь). Иконка ⚙️ — только у Папы → `/admin/settings`.

**Блок 01 — ВЫБОР СУНДУКА**

Два варианта (как кнопки выбора сферы):

- `🏆 НАГРАДЫ` — золотой акцент при выборе
- `⚠️ ПОСЛЕДСТВИЯ` — красный акцент при выборе

**Блок 02 — ВЫБОР ИКОНКИ**

Сетка карточек 5×2 с иконками (только эмодзи, крупно, без подписи). Список меняется в зависимости от выбора в блоке 01:

Для НАГРАД: `🎮` `🍕` `🎬` `🧸` `🚗` `💰` `🏖️` `🎨` `🎉` `⭐`

Для ПОСЛЕДСТВИЙ: `📵` `🛏️` `🧹` `📚` `🚫` `🏃` `🍽️` `😶` `📝` `⚠️`

Выбранная иконка — подсвечена рамкой (золото или красный в зависимости от типа).

**Блок 03 — УРОВЕНЬ**

Четыре карточки в ряд:

Для НАГРАД: `⭐ Уровень 1` / `⭐⭐ Уровень 2` / `⭐⭐⭐ Уровень 3` / `⭐⭐⭐⭐ Уровень 4`

Для ПОСЛЕДСТВИЙ: `⚠️ Уровень 1` / `⚠️⚠️ Уровень 2` / `⚠️⚠️⚠️ Уровень 3` / `⚠️⚠️⚠️⚠️ Уровень 4`

**Блок 04 — НАЗВАНИЕ**

`textarea`, 140 символов, счётчик снизу. Плейсхолдер: `Введите описание...`

**Кнопка:**

`СОХРАНИТЬ 🚀` — активна только если выбраны блоки 01, 02, 03 и заполнен блок 04.

При нажатии — анимация успеха (краткая вспышка/пульс), форма сбрасывается. Реальное сохранение в БД — позже.

**Список добавленного (ниже кнопки):**

Заголовок: `ДОБАВЛЕНО`

Список карточек в стиле журнала, сгруппированных по типу и уровню. Пока — хардкод 3–4 примера для демонстрации вёрстки:

## Задача 4 — Создать `/admin/settings`

Новый экран. Только для роли Папа (кнопка ⚙️ в шапке других экранов не отображается у Мамы и Бабушки).

**Шапка:**
`← (назад на /admin/event) | ПАПА / НАСТРОЙКИ`

Макет: вертикальный скролл, секции с заголовками в стиле других admin-экранов.

---

### Секция «ФОРМУЛА ЭНЕРГИИ»

**Делитель кривой k**
Слайдер: min 10, max 60, шаг 1, значение по умолчанию: `30`
Подпись: `Влияет на скорость набора энергии. Больше = медленнее.`

**Коэффициент затухания**
Слайдер: min 0.80, max 0.99, шаг 0.01, значение по умолчанию: `0.92`
Подпись: `Каждую ночь S × коэффициент. Меньше = быстрее забывается.`

---

### Секция «ПОРОГИ СОСТОЯНИЙ СТАНЦИИ»

Два поля ввода (число):

**Порог плюса (E):** по умолч. `+50`
Подпись: `Выше этого значения — станция синяя, начинается отсчёт дней для наград. Между 0 и порогом — /warning.`

**Порог минуса (E):** по умолч. `−50`
Подпись: `Ниже этого значения — /critical, начинается отсчёт для последствий. Между 0 и порогом — /danger.`

---

### Секция «ЗНАЧЕНИЯ СИЛЫ СОБЫТИЙ»

15 числовых полей ввода в три строки:

**Хорошее (5 полей):** `+5` / `+10` / `+20` / `+30` / `+50`

**Нейтральное (5 полей):** `−2` / `−1` / `0` / `+1` / `+2`

**Плохое (5 полей):** `−5` / `−10` / `−20` / `−30` / `−50`

Стиль: как кнопки «03 СИЛА» на `/admin/event`, но редактируемые (input[type=number]).

---

### Секция «ПОРОГИ СУНДУКОВ — НАГРАДЫ»

4 строки, каждая: уровень + поле «дней в зоне»:

| Уровень | Срабатывает чз N дней |
|---------|---------------|
| Уровень 1 | `1` |
| Уровень 2 | `7` |
| Уровень 3 | `14` |
| Уровень 4 | `30` |

---

### Секция «ПОРОГИ СУНДУКОВ — ПОСЛЕДСТВИЯ»

Аналогично:

| Уровень | Срабатывает чз N дней |
|---------|---------------|
| Уровень 1 | `1` |
| Уровень 2 | `3` |
| Уровень 3 | `7` |
| Уровень 4 | `14` |

---

### Секция «PIN-КОДЫ»

**Сменить свой PIN** — кнопка → inline-форма: старый PIN (4 цифры) + новый PIN + подтвердить

**Сбросить PIN Мамы** — кнопка → inline-форма: новый PIN + подтвердить

**Сбросить PIN Бабушки** — кнопка → inline-форма: новый PIN + подтвердить

---

### Кнопка внизу

`СОХРАНИТЬ НАСТРОЙКИ` — при нажатии: анимация успеха + надпись «Настройки сохранены ✓». Реальное сохранение — на бэкенде позже.
